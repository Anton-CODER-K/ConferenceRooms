# ConferenceRooms

1. Створіть PostgreSQL Базу даних з назвою:
   ConferenceRoomsDB

2. Запустіть:
   Database/init.sql

3. Налаштуйте рядок підключення:

   "ConnectionStrings": {
       "DefaultConnection":
           "Host=localhost;Port=5432;Database=ConferenceRoomsDB;Username=postgres;Password=..."
   }

4. Запустіть API.
